### Start of class / end of class routine

**Start of class**

*note: these instructions may vary depending on what you've named your repo/conda environment, and where you've stored your project. instructions below assume you have followed the specific instructions walked through on the first day of class.*

1. Open Terminal
2. If the prompt does not already read `(INFO-664)...`, type in `conda activate INFO-664` and hit return
3. (optional) - navigate to your repository's directory. type `cd ~/Documents/GitHub/INFO-664` into the terminal and hit enter (assuming that is the directory where your project is stored)
4. type `jupyter lab` into your terminal and hit enter

*note: typically, when you hit the up arrow on your keyboard in the terminal, it will show you a history of prompts you have made, saving you time typing!*

**End of class / as you work on notebooks outside of class**

1. Save your notebook into a subfolder of your repo whose name corresponds with the given week. For example:
```
INFO-664/
├── week01/
│   └── week01.ipynb
```

2. Go to GitHub desktop. First, summarize your changes in the "Summary" field - for instance `week 2 notebook added`. Then, press the "Commit to **main**" button. Finally, press the "Push origin" button, which will submit your changes to GitHub.

*note: it is a good idea to commit/push often to back up your work*

**Submitting notebooks and code challenges before subsequent class**

1. Assuming you have made your repo up to date with any additional changes, copy the URL that points to your week's notebook (for instance, `https://github.com/craigfahner/INFO-664/tree/main/week1`)
2. Submit that notebook to the Canvas assignment dropbox for the given week's notebook ahead of class time.
