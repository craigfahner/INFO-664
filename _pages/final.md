# Final Project Info

For the final project, you will find data of your choosing, and use Python to examine and produce inferences from that dataset. The finished project will consist of a Python notebook that contains the code that forms the basis of your analysis, and a GitHub pages website that documents your process and findings. That documentation will consist of the following components:

- A project overview
- A statement of “rationale” - why are you looking at this data? What hypotheses were you looking to assess?
- Your workflow:
    - What sources did you use?
    - What are the components of your Python code as they relate to the dataset / data collection process – data cleaning, sorting, filtering, counting, etc.
    - What challenges did you encounter and how did you solve them?
    - Include visual outputs, if applicable
- Your findings: Summarize what your analysis revealed about the data

Your final project proposal is due on October 5th at 6:30pm.
